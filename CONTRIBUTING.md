# Contributing to SkillsTree

First off, thank you for considering contributing to SkillsTree! It's people like you who make the Minecraft community such a great place.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue on our GitHub repository. Be sure to include:
- A clear and descriptive title.
- Steps to reproduce the bug.
- Your server version (Spigot/Paper).
- Any relevant logs or stack traces.

### Suggesting Enhancements
We love hearing new ideas! If you have a suggestion:
- Check if the feature has already been suggested.
- Open an issue and describe the feature in detail.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Ensure your code follows the existing style.
4. Submit a pull request with a clear description of your changes.

## Development Setup

This project uses **Maven**. To get started:
1. Import the project into your IDE (IntelliJ IDEA is recommended).
2. Maven will automatically download the required dependencies.
3. Use `mvn clean package` to build the project.
