# SkillsTree 🌳

![SkillsTree Header](skillstree_header_1778075874541.png)

**SkillsTree** is a premium, highly-optimized Minecraft Spigot/Paper plugin that integrates seamlessly with **ProjectKorra** to provide a rich, interactive skill tree experience. Empower your players with custom abilities, cosmetic effects, and a robust progression system.

## ✨ Features

- **Dynamic GUI Tree**: Intuitive menu interface for navigating and unlocking skills.
- **ProjectKorra Integration**: Automatically scans and loads abilities from ProjectKorra.
- **Vault Economy Support**: Optional integration for purchasing skills and cosmetics.
- **Cosmetic Effects**: Unlockable particle effects and trails to make players stand out.
- **AFK-Aware Progression**: Intelligent point distribution system that distinguishes between active play and AFK time.
- **Asynchronous Persistence**: High-performance data saving that never lags your server.

## 🛠 Installation

1. **Requirements**:
   - Spigot/Paper 1.21 or higher.
   - [ProjectKorra](https://projectkorra.com/)
   - [Vault](https://www.spigotmc.org/resources/vault.343/) (Optional, for economy features).
2. Download the latest `SkillsTree.jar` from the [Releases](https://github.com/Furthy/SkillsTreeProject/releases) page.
3. Place the JAR into your server's `plugins/` directory.
4. Restart your server to generate the configuration files.
5. Configure the plugin in `plugins/SkillsTree/config.yml`.

## 🎮 Commands & Permissions

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/st` | Opens the main Skills Tree menu. | `skillstree.use` |
| `/st reload` | Reloads the plugin configuration. | `skillstree.admin` |

## 🏗 Building from Source

This project uses **Maven** for dependency management and builds.

1. Clone the repository:
   ```bash
   git clone https://github.com/Furthy/SkillsTreeProject.git
   ```
2. Navigate to the project directory:
   ```bash
   cd SkillsTreeProject
   ```
3. Build the project:
   ```bash
   mvn clean package
   ```
4. The compiled JAR will be located in the `target/` directory.
